Detailed Description

Represents a GENEVE (Generic Network Virtualization Encapsulation) protocol layer. Layer methods assume that the fixed header and its declared options area are complete. Data passed to the raw-data constructor must first pass isDataValid(); crafted layers establish this layout internally. Callers modifying raw layer data must preserve this layout. Individual options may still be malformed and are checked during traversal.
