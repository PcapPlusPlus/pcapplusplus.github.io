Detailed Description

Serializes a collection of packets into a single array. The array is opened immediately in the constructor and closed when the PacketSerializer is destroyed, so all packets must be added within its lifetime. Not copyable, since copying would either double-write the array or leave one copy's array permanently unclosed.
