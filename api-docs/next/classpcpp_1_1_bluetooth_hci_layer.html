Detailed Description

An abstract base class for all Bluetooth HCI packet types. It handles the parts common to every HCI packet: the optional direction pseudo-header and the H4 packet indicator octet. Concrete subclasses parse a specific packet type and are created through BluetoothHciLayer::parseLayer()
